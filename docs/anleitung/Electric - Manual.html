Electric

Display for electric planes · Manual · Version 0.7.6 · 22 Nov 2026

Electric is a display (a «widget») for FrSky radios running Ethos. On a full screen it shows the flight battery, cells, current, RPM, ESC temperature, power, altitude, speed and signal of your electric plane. It watches the values in two stages, announces alarms and the battery level and keeps a list of your flights. The pictures in this manual show the German display except where noted; the English display uses the same layout.

Test status: Tested in the Ethos simulator 26.2.0 (X18RS) with 19 test runs, 800 × 480 directly, 640 × 360, 480 × 320 and 480 × 272 simulated. Tested on a real X18RS (Ethos 26.2.0, 20 Nov 2026): display and automatic sensor search with 48 sensors, compact view and throttle %, with version 0.3.0 the Lua-Studio settings file (without telemetry: no file, demo file, changes in the .funke.lua, broken file, transfer from Lua-Studio); with telemetry (0.3.1) display, sensor search, motor switch, an alarm with the switch armed and off, flight detection and flight list; with version 0.4.0 a full format-2 file (16 symbols, bold unit, decoration) and 10 model changes without errors, a layout with symbols from Lua-Studio; not yet checked: compact view and English with a settings file. Version 0.5.0 (memory freed on model change, «Alarm also with motor off», «Loading Studio file» display) so far only checked in the simulator and on the Mac. The voice announcements were checked with version 0.1.2. Not yet flown, not every menu item checked one by one, other radios only in the simulator.

1. What you need

  • A FrSky radio with Ethos 26.2 (tested) and a colour display (list at the end).
  • An electric model with telemetry, sensors already discovered (Model › Telemetry › Discover sensors). At least the pack voltage is needed; current, consumption, RPM, temperature, altitude, speed and a cell sensor are optional.
  • A computer with FrSky Suite and a USB cable.
  • The file Electric-0.7.6.zip. It is inside Electric-0.7.6-share.zip. Unzip only the outer ZIP, not the inner one.

2. Install

  1. Switch the radio on and connect it to the computer with the USB cable.
  2. The radio shows a choice. Select Ethos Suite.
  3. Open FrSky Suite on the computer. The radio appears at the top.
  4. Click Lua library, then Install from local ZIP.
  5. Select Electric-0.7.6.zip. The Suite copies everything to the right place.
  6. Unplug the cable and restart the radio.

Without the Suite: connect the radio as «USB storage» and copy the folder electric from the ZIP into scripts. If your radio loads scripts from the SD card (System › General › Storage location), it belongs in scripts on the SD card. Overwrite an existing folder, do not delete it.

3. Set up the screen

  1. Tap the Screens icon at the bottom (two rectangles).
  2. Tap + at the top right.
  3. Swipe down to the layout Full screen (one large field) and tap it. To keep the Ethos top and bottom bars, choose the layout with one field and the bars instead (bottom centre of the layout grid); Electric then shows the compact view (chapter 5).
  4. Tap the empty field, then Widget.
  5. Swipe to the bottom of the list and select Electric. The display appears at once.

You reach the widget menu any time through Model › Screens › select the screen › tap the widget.

4. Sensors and battery

  1. Switch the model on so telemetry runs. The first time, Electric finds the sensors itself; a short blue note «… sensors assigned automatically» appears.
  2. Open the menu and the group Sensors. Check every line and select missing or wrong ones by hand. An empty line is allowed; the field then shows a dash.
  3. Find sensors (empty only) › Search later fills only empty lines; your own choices stay. If you deleted sensors in Ethos and searched again, first reload the model (select another model and back), otherwise the values stay at 0. Then the search binds each line to the matching sensor (same ID and name); lines whose sensor is no longer in the sensor list, including ones you chose yourself, are searched again.
  4. The group Check assignment shows each chosen sensor with physical ID and AppID (e.g. «ESC Current P04 / 0B50»). If several identical sensors matched, a line «n sensors match, chosen: … - please check» follows.
  5. Open the group Battery and set Battery type, Cell count and Capacity of your flight pack.

A short grey dash instead of a number means: this value is not arriving or has no sensor. You choose what each gauge and field shows in the menu (chapter 8, group Fields).

Battery % comes from the ESC if it sends it and «Battery % from» is «ESC, else calculated». Otherwise Electric calculates: when the model rests 2 seconds without current, it takes the start value from the resting voltage (curve of the battery type) and then counts down with the used mAh and the capacity. «REST» then appears below the gauge. The menu line «Battery % from» shows what applies.

New pack: if telemetry is gone for more than 30 seconds (pack unplugged), MAX and LOW values, Wh and battery % start again.

Compact view

If you choose the layout with top and bottom bars (chapter 3), Electric notices it and shows a compact view: a narrow bar with flight time, ARMED / MOTOR OFF and signal (model name and radio battery are in the Ethos top bar), below it the four gauges and eight fields: the large field (THROTTLE by default, here without bar), fields 1 to 6 and FLIGHTS. Tap FLIGHTS to open the flight list. Everything else works as in the full screen.

Compact view on X20 and X18RS (784 × 316). On X14 and X18 / Twin X Lite it is smaller accordingly.

6. Warnings and alarms

Every monitored value has two limits: warning (orange, display only) and alarm (red, frame, tone and announcement). Set both in the menu group Limits; 0 switches a limit off. Defaults:

Warning: top bar and value orange, no tone
Alarm: top bar red, red frame, tone and voice

A warning appears when the value is beyond the limit for 1 second and disappears when it is good again for 3 seconds. An alarm beeps, announces the value and repeats every 10 seconds («Repeat alarm every») as long as it lasts. There are always at least 3 seconds between two announcements.

Alarm also with motor off (from version 0.5.0): by default all warnings and alarms also come when the motor switch is set to «off». In the menu group Alarm also with motor off you can turn this off per value. That value then stays silent while the motor switch is set to «off»: no message, no tone, no announcement, no vibration. The colour of the value still shows the limit. As soon as you arm the motor, the alarm comes back. Without a motor switch set, this setting never applies.

7. Operation

Detecting flights

By default Electric detects a flight by the motor switch: «Motor off at» is SF↑. Arm the motor and the flight time starts; switch it off and the radio says «Motor off», the time stops and the question «Flight ended?» appears.

  • YES, ENDED: the flight goes into the list.
  • NO, JUST PAUSE: the flight stays open. Arm the motor again and it continues.
  • A paused flight ends by itself when you unplug the pack (telemetry gone for over 30 s, «Battery change ends flight»).

A flight counts only after 30 seconds of motor time («Flight counts from»); shorter runs on the ground are dropped. Without a motor switch, or with «Detect flight by» = «Current or throttle», the flight starts as soon as the current is above 3 A or the throttle above 10 %, and the pause with the question comes after 20 seconds below.

Flight list (page 2)

Swipe left or tap «8 flights». The flights are on the right, newest first, the current one in blue with «running» or «paused». Tap a flight and its values appear on the left. The rotary encoder also selects flights.

  1. Delete one flight: tap it, DELETE FLIGHT n, then YES, DELETE. The later numbers move up.
  2. Delete all flights: CLEAR LIST, then YES, DELETE. The counter starts at 1 again.
  3. Back to the display: < BACK or swipe right.

The list keeps the last 20 flights. It survives switching off. A paused flight is closed at the next switch-on and goes into the list (if «Battery change ends flight» is on).

Used capacity to 0

Tap RESET in the USED field and confirm with YES, RESET. CANCEL leaves everything as it is.

Announcement on a switch

Switch SG↓ on («Announce at») and the radio announces battery level and flight time. Choose what is announced in the group Announcements. In addition Electric announces the battery level every 10 % while discharging («Announce battery % every»).

Radios without touch (X14, X10, X12)

At the top of the menu there are Reset capacity, Delete flight (first choose the number at «Flight no. to delete») and Delete whole list, each with a question. The rotary encoder takes you to the flight list and selects flights; turning back before the first flight returns to the display.

Settings file from Lua-Studio

With the PC program Lua-Studio you design the display freely for each model: for every box you choose the value, the display type (number, gauge, horizontal or vertical bar, graph, status), title, range, colours and an extra line (MIN, MAX or Ø over the flight). Settings and limits per model come with it. Lua-Studio writes the file scripts/studio/modelname.electric.lua to the SD card. In the file name, only the letters A–Z and digits of the model name are kept, everything else becomes _ («Möwe 2» becomes M__we_2); Lua-Studio does this itself. Electric reads it when the model is loaded.

  • Without this file Electric works exactly as before, without any message.
  • Where and which file (from 0.7.6): Electric looks for the file in scripts/studio in the set script location, then on the SD card, then in the internal memory. If the file name does not match the model name, choose the file in the widget menu under Studio layout (the list shows every file with its location; «automatic (model name)» is the previous way). The choice in the menu wins over the model name.
  • With the file its layout applies to the window size it was made for. If there is no layout for this size, Electric 0.7.6 adapts the layout with the most similar aspect ratio and shows «Studio: view 800x480 adapted» in the header for 5 s. Boxes that get too small are shown as a number or left out. If the built-in display stays although there is a file, the header gives the reason, e.g. «Studio: file broken (…)» or «Studio: no matching view».
  • After a model change Electric reads the file in small steps, which can take a moment. If the file has a layout for this window size, it shows «Loading Studio file ...» meanwhile instead of the built-in display; otherwise Electric shows its built-in display right away.
  • Symbols, bold unit and decoration (from version 0.4.0, Lua-Studio 0.3.0 or newer): a box can show a symbol at the top left (e.g. battery, clock, altitude) and the unit in bold. Freely placed symbols, texts, lines and frames can sit under the boxes. Lua-Studio writes the images to scripts/studio/symbole/. If an image is missing or broken, Electric shows the box without the symbol and briefly «Studio: n symbols missing» at the bottom. Symbols and decoration never change a limit or an alarm.
  • Limits apply per value, whether and however it is shown. If a value is missing in the file, the factory limit applies. An alarm is only switched off if the file says so explicitly. If an entry does not fit the value (e.g. wrong direction), the factory limit applies as well, with a message. «Also with motor off» can be set per limit in Lua-Studio too (from version 0.5.0, also for sensors and channels). The radio menu only lists Electric's own 10 values; limits for sensors and channels from the file are set in Lua-Studio.
  • If you change battery, limits or other settings in the menu on the radio, Electric writes this to its own file …electric.funke.lua. The Lua-Studio file stays unchanged. Lua-Studio shows the differences and takes them over on request.
  • Menu › Studio file › Reset: with a file «Back to Studio settings» (your changes on the radio are deleted), without a file «Back to defaults» (factory settings and limits; sensors and flights stay). Both ask first.
  • Messages: if the file is broken, too new or contains invalid entries, a band at the bottom shows it for 8 seconds (e.g. «Studio file broken - default»), then an orange «!» stays at the top right. Electric always keeps running, if in doubt with the built-in display.
  • Electric also writes …electric.info.json with model name, radio and sensor list. Only Lua-Studio reads it.

10. Update and remove

Update: install the new ZIP exactly as in chapter 2. Your settings, sensors, flights and counters are kept.

Upgrading from Elektro (up to 0.5.0): from 0.6.0 the widget is called Electric (folder scripts/electric, Studio file ….electric.lua). After installing, add the widget again in every model (assign sensors and switches again; settings, counters and flights from scripts/elektro/daten are taken over automatically); re-transfer Studio files from Lua-Studio. An old ….elektro.lua is still read for now. Delete the folder scripts/elektro afterwards.

Remove: first take the widget off the screen (Model › Screens), then uninstall it in FrSky Suite under Lua library.
